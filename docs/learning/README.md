# エージェントの仕組みを理解する — SkillTrace 学習ドキュメント

SkillTrace（Copilot のスキル読み込みを可視化するツール）に出てくる言葉を手がかりに、
LLM エージェントの仕組みを理解するための読み物です。

進め方の約束:

- **ツールの画面に出てくる言葉から入る**。抽象的な概念論はしない。
- **実例は全部、本物のセッションの数値**（確認用ダミースキル phase0-probe を
  Copilot に実行させたときの記録）を使う。再現実験の方法も付ける。
- 1つの概念につき1ファイル、10分で読める長さにする。
